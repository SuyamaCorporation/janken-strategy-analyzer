## じゃんけん心理戦略アナライザー

対AI対戦のじゃんけんで選択バイアスをリアルタイム分析し、マルコフ連鎖予測AIとの対戦を通じて行動経済学を体験できる教育ゲーム。

### 機能
- グー・チョキ・パーの3ボタンによるじゃんけん対戦
- AI戦略3モード: ランダム・心理AIv1（頻度分析）・心理AIv2（マルコフ連鎖予測）
- リアルタイム統計4タブ:
  - 出現頻度バーグラフ（グー/チョキ/パーの割合）
  - 直前の手→次の手の遷移マトリクス（ヒートマップ色付き）
  - 心理バイアス解説（勝/負/引分け後の行動パターン分析）
  - 勝率推移グラフ（Canvas描画・直近50戦のローリング勝率）
- 50戦ごとの「あなたの弱点パターン」自動診断
- localStorage による全対戦履歴保存

### 技術
- 静的SPA（index.html単体）
- Tailwind CSS CDN
- Canvas 2D API による勝率推移グラフ描画
- マルコフ連鎖による行動予測AI
- localStorage 永続化
